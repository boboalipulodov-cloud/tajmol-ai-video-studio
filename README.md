# TAJMOL AI VIDEO STUDIO — Full-stack starter

Ин версия аз прототипи оддӣ як қадам пештар аст: интерфейси веб + се API route-и серверӣ.

## Имкониятҳо
- **Матни AI:** Gemini API барои сохтани матни реклама.
- **Овози AI:** ElevenLabs API барои матн ба MP3. ElevenLabs v3 рӯйхати забонҳои дастгиришавандаашро дорад, аз ҷумла тоҷикӣ (`tg`); талаффуз аз овози интихобшуда вобаста аст.
- **Видео AI:** fal.ai — расмро ба видео табдил медиҳад. Расм аввал аз сервер ба storage-и fal бор мешавад; калиди API дар браузер нишон дода намешавад.
- Интерфейси мутобиқ ба телефон, планшет ва компютер.

## Муҳим
Ин ҳоло **starter-и омода барои пайвасткунӣ** аст, на сайти нашршуда. Барои фаъол шудани генераторҳо API key ва ҳисоби провайдерҳо лозим аст. Сохтани видео ва овоз метавонад пулакӣ бошад. Барои корбарони ройгон баъдтар лимит, ҳисоб ва пардохт бояд илова карда шавад. Дар ин версия аккаунт/пардохт/базаи маълумот нест.

## 1. Пеш аз ҳама
Дар компютер Node.js 20.9 ё навтар насб кунед. Лоиҳаро аз ZIP берун кунед ва дар папкаи он терминал кушоед:

```bash
npm install
```

## 2. Калидҳои API
Файли `.env.example`-ро ба `.env.local` нусха кунед ва қиматҳоро пур кунед:

- `GEMINI_API_KEY` — аз Google AI Studio: https://aistudio.google.com/app/apikey
- `FAL_KEY` — аз панели fal.ai: https://fal.ai/dashboard/keys
- `ELEVENLABS_API_KEY` — аз панели ElevenLabs: https://elevenlabs.io/app/settings/api-keys
- `ELEVENLABS_VOICE_ID` — ID-и овози интихобкардаатон аз Voice Library.

**Калидҳоро ба касе нафиристед, дар GitHub нагузоред ва ба номи `NEXT_PUBLIC_...` нагузоред.** Танҳо дар `.env.local` ё Environment Variables-и хостинг нигоҳ доред.

## 3. Иҷрои маҳаллӣ
```bash
npm run dev
```
Баъд дар браузер кушоед: http://localhost:3000

## 4. Нашр дар интернет
1. Лоиҳаро ба GitHub repository-и нави худ бор кунед.
2. Дар Vercel ба GitHub пайваст шавед ва ин repository-ро интихоб кунед.
3. Дар Project Settings → Environment Variables ҳамаи тағйирёбандаҳои `.env.local`-ро илова кунед.
4. Deploy кунед.
5. Пас аз тағйири калидҳо Redeploy кунед.

Сомона дар браузери Android, iPhone ва компютер кор мекунад.

## 5. Чизҳое, ки барои маҳсулоти воқеӣ ҳанӯз бояд илова шаванд
- Сабти ном ва воридшавӣ.
- Пойгоҳи додаҳо ва таърихи лоиҳаҳо.
- Лимити ройгон, бастаҳои Premium ва пардохти бехатар.
- Маҳдуд кардани шумораи дархостҳо (rate limiting), санҷиши abuse ва мониторинги хароҷот.
- Санҷиши овози тоҷикӣ бо якчанд voice ID.
- Барои production: upload storage-и хусусӣ ва идоракунии мӯҳлати нигоҳдории файлҳо.

## API model defaults
- Gemini: `gemini-2.5-flash`
- fal video: `wan/v2.6/image-to-video`
- ElevenLabs: `eleven_v3`

Агар endpoint ё параметрҳои модели видео дар ҳисоби fal тағйир ёбанд, `FAL_VIDEO_MODEL` ва input schema-ро мувофиқ кунед.
